# Лабораторна робота № 8 — MYSPACE

**Тема:** Робота з Git та публікація сайту через GitHub Pages.  
**Варіант:** 3. **Номер у списку:** 12.

## Про проєкт
Навчальний адаптивний сайт із трьох сторінок для практики HTML, CSS, Git і GitHub Pages.

## Сторінки
- `index.html` — головна сторінка та інформація про автора.
- `task.html` — таблиця шести валют: UAH, USD, EUR, MXN, BRL, SGD.
- `team.html` — сторінка «Учасники моєї команди»: Struk V., Tsvigun V., Homa A.
- `style.css` — спільне оформлення сайту.

## Посилання на сайт
Після публікації через GitHub Pages встав сюди адресу: `ВСТАВ_ПОСИЛАННЯ_САЙТУ`

## Примітка
Курси в таблиці умовні та призначені лише для демонстрації HTML-таблиці. Вони не є актуальними фінансовими котируваннями.
